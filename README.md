🔐 CrackHash – Password Hash Cracking Tool

CrackHash is a powerful Python-based tool designed to crack hashed passwords using multiple algorithms such as MD5, SHA1, and SHA256. It supports both CPU and optional GPU-based cracking techniques to improve performance and speed.

This tool is ideal for cybersecurity learners, ethical hackers, and penetration testers who want to understand password security and hash vulnerabilities.

🚀 Features

🔑 Supports multiple hash algorithms:

MD5

SHA1

SHA256 (SHA2)

⚡ Fast cracking using dictionary/brute-force methods

🖥️ CPU-based cracking (default)

🚀 Optional GPU acceleration support

📂 Custom wordlist support

🛠️ Easy-to-use command-line interface

📊 Displays cracking progress and results

🧰 Technologies Used

Python 3

Hashlib

Optional: CUDA / GPU libraries
